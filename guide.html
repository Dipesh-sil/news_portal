1. One-Time Setup (for Admin/Developer)

Before your client can use the dashboard, you (the developer) need to create a GitHub token for them. This only needs to be done once.

Create a GitHub Personal Access Token

1 Go to GitHub Token Settings

Open this URL in your browser:
https://github.com/settings/tokens?type=beta
(This opens Fine-grained Personal Access Tokens page)

2 Click "Generate new token"

Choose Fine-grained personal access token (recommended for security).

3 Configure the token

Token name: bullet-khabar-admin
Expiration: 90 days or Custom (set a reminder to renew)
Repository access: Select "Only select repositories" → choose bullet-khabar
Permissions → Repository permissions:

PermissionAccess Level
ContentsRead and write
MetadataRead-only (auto-selected)

Leave all other permissions as "No access".

4 Generate & copy the token

Click "Generate token". Copy the token immediately — you won't see it again!
It looks like: github_pat_xxxxxxxxxxxx...

Keep this token secret! Anyone with this token can edit your news content. Never share it publicly.

2. How to Give Client Access

Your client does NOT need a GitHub account or any technical knowledge. You just give them 3 things:

Send these 3 things to your client (via secure message/email):
#What to SendExample
1 Dashboard URL https://bulletkhabar.com.np/admin
2 GitHub Token github_pat_xxxxxxxxxx...
3 Repository Name yourusername/bullet-khabar

That's it! The client opens the URL, enters the token and repo name, and they're in.

Access Levels

RoleWhat They GetHow
News Editor / Client Write articles, upload images, manage jobs/notices/banners Dashboard URL + Token + Repo name
Developer / Admin Everything above + code access, deployment, settings GitHub repo owner access

Multiple Editors

To give access to multiple people (e.g., 3 journalists), you can either:

  • Option A: Share the same token with all editors (simpler)
  • Option B: Create separate tokens for each person (more secure — you can revoke one person's access without affecting others)

3. How to Login to Dashboard

1 Open the Admin Dashboard

Go to your website URL with /admin at the end:

https://your-domain.com/admin
2 Enter your credentials

GitHub Token: Paste the token you received
Repository: Enter the repo name (e.g., username/bullet-khabar)

3 Click "Login to Dashboard"

Your credentials are saved in your browser. You won't need to login again on the same browser unless you clear your data or click Logout.

Your login is saved locally in your browser only. It is not sent to any server. Each device/browser needs its own login.

4. How to Write & Publish an Article

1 Click "New Article" in the sidebar

Or click the blue "+ New Article" button on the dashboard.

2 Fill in the article details

The editor has two columns — English on the left, Nepali on the right:

FieldWhat to Enter
English TitleThe headline in English
Nepali TitleThe headline in Nepali (नेपाली शीर्षक)
DatePublication date (auto-filled with today)
BS DateNepali date, e.g. २०८३ चैत्र १७
CategoryClick one: Nepal, Politics, World, Business, Sports, Technology
AuthorWriter's name
Featured ImageUpload or drag & drop an image (see Section 5)
English TL;DR3 bullet points separated by |
Example: Point one|Point two|Point three
Nepali TL;DRSame format in Nepali: बुँदा एक|बुँदा दुई|बुँदा तीन
English ContentFull article body in English
Nepali ContentFull article body in Nepali
3 Check "Published" checkbox

If unchecked, the article is saved as a draft and won't appear on the website.

4 Click "Publish Article"

The article is saved to GitHub and will appear on the website within 1-2 minutes after Cloudflare rebuilds the site.

AI Assist Buttons: The "AI Generate" buttons next to TL;DR fields can auto-generate bullet point summaries from your article content (requires Gemini API key in Settings).

5. How to Upload Images

Images are hosted for free in your GitHub repository and served through Cloudflare CDN (fast worldwide).

Method 1: Drag & Drop (Recommended)

1 Find the "Featured Image" section in the article editor

You'll see a dashed-border upload area.

2 Drag an image file from your computer and drop it on the upload area

Or click the area to browse and select a file.

3 Wait for upload

You'll see "Uploading to GitHub..." then "Uploaded!" when done. A preview will appear above.

Method 2: Manual Path

If you've already uploaded images to the GitHub repo, type the path directly in the text field below the upload area:

/images/uploads/my-photo.jpg

Image Guidelines

RuleRecommendation
FormatJPG, PNG, or WebP
Max Size5 MB per image
Ideal Dimensions1200 x 630 px (16:9 ratio, best for social sharing)
NamingUse descriptive names: nepal-flood-2026.jpg
Where are images stored? Images are uploaded to public/images/uploads/ in your GitHub repository. They are served through Cloudflare's global CDN for fast loading worldwide. This is 100% free — no hosting costs.

Removing an Image

Click the X button on the top-right corner of the image preview to remove it from the article. (The file stays in GitHub — to delete it permanently, remove it from the repo.)

8. Troubleshooting

ProblemSolution
"Login required to upload" You're not logged in. Enter your GitHub token and repo name on the login screen.
Image upload fails Check that your GitHub token hasn't expired. Generate a new one if needed.
Article not appearing on site Wait 2 minutes for Cloudflare to rebuild. Also check if "Published" checkbox was ticked.
"Error: Resource not accessible" Your GitHub token doesn't have "Contents: Read and write" permission. Create a new token with correct permissions.
Dashboard shows blank page Clear browser cache (Ctrl+Shift+Delete) and reload.
Token expired Go to GitHub Settings → Tokens → Generate a new one. Enter it on the login screen again.
Want to remove someone's access Go to GitHub Settings → Tokens → Delete their token. They can no longer publish.
